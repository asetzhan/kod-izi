# «Код ізі»: Claude Code-қа арналған бастапқы пакет

## Орнату және іске қосу

### Не керек

- Docker және Docker Compose v2 (`docker compose version` жұмыс істеуі керек);
- Make;
- Git.

Ubuntu-да орнату:

```
sudo apt install docker.io docker-compose-v2 make git
sudo usermod -aG docker $USER   # содан кейін жүйеден шығып, қайта кіріңіз
```

### Бірінші іске қосу

```
git clone https://github.com/asetzhan/kod-izi.git
cd kod-izi
make dev
```

`make dev` бірінші рет іске қосылғанда `.env.example` файлынан `.env` жасайды. Құпиясөздер мен кілттер автоматты түрде кездейсоқ мәндермен толтырылады. Содан кейін барлық сервис көтеріледі: Nginx, frontend, backend, RQ worker, PostgreSQL (pgvector-пен), Redis және Judge0. Дерекқор миграциялары өздігінен орындалады.

Жүйе мына мекенжайда ашылады: http://localhost:8080 (порт `.env` ішіндегі `HTTP_PORT` айнымалысымен өзгереді).

### Пайдаланушылар

Жүйеде өздігінен тіркелу жоқ: пайдаланушыны әкімші қосады.

```
make create-admin EMAIL=siz@example.com   # бірінші әкімші, құпиясөзді сұрайды
make seed                                 # тек әзірлеу үшін: төрт рөлдің демо-аккаунттары
```

`make seed` курстар каталогын, білім компоненттерін және 9 эксперимент тапсырмасының жобасын жүктейді. Dev ортасында ол мына аккаунттарды да жасайды: `student@example.com`, `student2@example.com`, `teacher@example.com`, `coach@example.com`, `admin@example.com`. Құпиясөз `.env` ішіндегі `DEMO_PASSWORD` мәні болады. Ол бос болса, жаңа құпиясөз жасалып, экранға бір рет шығарылады. Бұл команда тек `APP_ENV=dev` кезінде жұмыс істейді.

### Командалар

| Команда | Не істейді |
| --- | --- |
| `make dev` | Барлық сервисті іске қосады |
| `make down` | Сервистерді тоқтатады |
| `make logs` | Сервистердің логын көрсетеді |
| `make migrate` | Alembic миграцияларын орындайды |
| `make seed` | Курстар каталогын (Stepik сабақтары), білім компоненттерін және эксперимент тапсырмаларының жобасын жүктейді; dev ортасында демо-аккаунттарды да жасайды |
| `make create-admin EMAIL=...` | Бірінші әкімшіні жасайды |
| `make test` | Backend (pytest) және frontend (vitest) тесттері |
| `make lint` | ruff, mypy, bandit, eslint, tsc |

API құжаттамасы (тек dev ортасында): http://localhost:8080/api/docs

### Judge0 туралы ескерту

Judge0 1.13.1 студент кодын оқшауланған ортада орындау үшін cgroup v1-ді талап етеді. Ubuntu 22.04 және одан жаңа жүйелерде әдепкі бойынша cgroup v2 қолданылады. Мұндай жүйеде Judge0 іске қосылады, бірақ кодты орындай алмайды. 0-кезеңде бұл кедергі емес, өйткені код орындау 2-кезеңде басталады. Шешімі `docs/spec/questions.md` ішіндегі Q-15 сұрағында.

### Judge0-мен интеграциялық тест

Негізгі тесттерде Judge0 орнына fake клиент қолданылады. Нақты Judge0-мен тексеру (эталон шешімдер OK алады, әдейі қате шешімдер WA/TLE/MLE/RE/CE алады, студент коды желіге шыға алмайды) cgroup v1 бар машинада былай іске қосылады:

```
JUDGE0_TEST_URL=http://<judge0-мекенжайы>:2358 JUDGE0_TEST_TOKEN=<токен> pytest backend/tests/test_judge0_integration.py
```

### Жиі кездесетін қателер

- **`permission denied ... docker.sock`**: пайдаланушы `docker` тобында жоқ. `sudo usermod -aG docker $USER` командасын орындап, жүйеге қайта кіріңіз.
- **`port is already allocated`**: 8080 порты бос емес. `.env` ішінде `HTTP_PORT` мәнін өзгертіңіз.
- **Құпиясөзді өзгерткеннен кейін дерекқор ашылмайды**: PostgreSQL құпиясөзі тек дерекқор алғаш жасалғанда беріледі. Әзірлеу ортасында `docker compose -f infra/docker-compose.yml down -v` командасымен деректерді өшіріп, қайта бастауға болады.

## Қалай бастау керек

1. Бос репозиторий ашыңыз (мысалы, GitHub-та) және осы пакеттің мазмұнын оның түбіріне салып, коммит жасаңыз.
2. docs/spec/questions.md-ді ашып, Q-02 мен Q-03 сұрақтарына шешім жазыңыз.
3. Репозиторийді Claude Code-та ашыңыз.
4. docs/prompts/README.md-дегі тәртіппен 0-кезеңнен бастаңыз.

## Сізге қалатын жұмыс

Claude Code кодты, тесттерді және құжаттаманы жазады. Мына шешімдер мен әрекеттер сізде қалады:

- questions.md-дегі сұрақтарға жауап беру;
- әр кезеңнің жоспарын бекіту және нәтижесін қабылдау;
- педагогикалық мазмұнды тексеру: рубрика, деңгейлер, тапсырмалар, тесттер, LLM промпты;
- сервер, домен, LLM API кілттері — бұларды IT бөлімімен бірге;
- пилот алдында тәуелсіз ену тестін (pentest) ұйымдастыру.

## Маңызды ескертулер

- **Деңгей ережесі — ұсыныс.** Төрт белгі, 0–2 балл және шекті мәндер диссертацияда жоқ, оларды мен ұсындым (Q-06). Бекіткенше Claude Code оларды баптау ретінде жасайды.
- **LLM бағалау промпты — жоба.** Диссертациядағы тәжірибеде қолданылған нұсқаулықтың мәтіні диссертацияда жоқ (Q-10). Бар болса, docs/spec/dissertation/ ішіне салыңыз.
- **Stepik есептері тек сілтемемен беріледі.** Авторлардың рұқсаты болмаса, шарттары көшірілмейді (Q-05).
- **Құжатты жаңарту.** Claude Doc-тағы техникалық тапсырманы өзгертсеңіз, өзгерісті docs/spec-ке де енгізіңіз. Ол үшін templates.md-дегі «Талапты өзгерту» промптын қолданыңыз. Репозиторийдегі docs/spec — Claude Code үшін негізгі нұсқа.
