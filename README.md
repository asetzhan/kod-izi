# «Код ізі»: Claude Code-қа арналған бастапқы пакет

Бұл пакет — жаңа репозиторийдің бастапқы мазмұны. Оны бос репозиторийге салып, Claude Code-қа кезең-кезеңімен тапсырма бересіз.

## Ішінде не бар

| Жол | Мазмұны |
| --- | --- |
| CLAUDE.md | Claude Code әр сессияның басында оқитын тұрақты ережелер |
| docs/spec/ | Техникалық тапсырма, 17 бөлімге бөлінген; README.md — мазмұны |
| docs/spec/glossary.md | Қазақша терминдер және кодтағы атаулар |
| docs/spec/questions.md | Ашық сұрақтар мен шешімдер журналы |
| docs/spec/dissertation/ | Диссертациядан алынған кестелер: критерийлер, дескрипторлар, деңгейлер, интерпретация, эксперимент тапсырмалары; LLM бағалау промптының жобасы |
| docs/prompts/ | Әр кезеңнің промпты және қосымша промпттар |
| seed/ | Бастапқы деректер: Stepik сабақтары (ID-лерімен), әдепкі рубрика, деңгей ережесі, олимпиада ресурстары, эксперимент тапсырмалары |

## Қалай бастау керек

1. Бос репозиторий ашыңыз (мысалы, GitHub-та) және осы пакеттің мазмұнын оның түбіріне салып, коммит жасаңыз.
2. docs/spec/questions.md-ді ашып, Q-02 мен Q-03 сұрақтарына шешім жазыңыз.
3. Репозиторийді Claude Code-та ашыңыз.
4. docs/prompts/README.md-дегі тәртіппен 0-кезеңнен бастаңыз.

## Сізге қалатын жұмыс

Claude Code кодты, тесттерді және құжаттаманы жазады. Мына шешімдер мен әрекеттер сізде қалады:

- questions.md-дегі сұрақтарға жауап беру;
- әр кезеңнің жоспарын бекіту және нәтижесін қабылдау;
- педагогикалық мазмұнды тексеру: рубрика, деңгейлер, тапсырмалар, тесттер, LLM промпты;
- сервер, домен, LLM API кілттері — бұларды IT бөлімімен бірге;
- пилот алдында тәуелсіз ену тестін (pentest) ұйымдастыру.

## Маңызды ескертулер

- **Деңгей ережесі — ұсыныс.** Төрт белгі, 0–2 балл және шекті мәндер диссертацияда жоқ, оларды мен ұсындым (Q-06). Бекіткенше Claude Code оларды баптау ретінде жасайды.
- **LLM бағалау промпты — жоба.** Диссертациядағы тәжірибеде қолданылған нұсқаулықтың мәтіні диссертацияда жоқ (Q-10). Бар болса, docs/spec/dissertation/ ішіне салыңыз.
- **Stepik есептері тек сілтемемен беріледі.** Авторлардың рұқсаты болмаса, шарттары көшірілмейді (Q-05).
- **Құжатты жаңарту.** Claude Doc-тағы техникалық тапсырманы өзгертсеңіз, өзгерісті docs/spec-ке де енгізіңіз. Ол үшін templates.md-дегі «Талапты өзгерту» промптын қолданыңыз. Репозиторийдегі docs/spec — Claude Code үшін негізгі нұсқа.
