# Frontend ережелері

- Интерфейс мәтіні тек `src/i18n/kk.json` және `src/i18n/ru.json` файлдарында болады, екеуінің кілттері бірдей (`i18n.test.ts` тексереді). Компонентте `t("...")` қолданылады.
- API шақыруы тек `src/api/client.ts` арқылы жасалады. Access токен тек жадта сақталады, `localStorage`-қа жазылмайды.
- Рөлмен қорғалған бет `RequireRole` ішіне оралады. Бұл тек интерфейстің ыңғайы үшін: нақты тексеру серверде жүреді.
- `dangerouslySetInnerHTML` қолданылмайды. Markdown-ды көрсету керек болса, тазартатын кітапханамен ғана көрсетіледі.
- Тесттер vitest пен Testing Library арқылы жазылады. Файлдың аты `*.test.ts(x)` болады, тест атауында талап ID-і болады.
