## Әр кезеңнің тәртібі

1. docs/spec/questions.md-де осы кезеңге керек сұрақтарға шешім жазыңыз.
2. Claude Code-та жаңа сессия ашып, жоспарлау режимін (plan mode) қосыңыз.
3. Кезең промптын толық көшіріп беріңіз.
4. Ұсынылған жоспарды оқыңыз. Түсініксіз немесе артық нәрсе болса, сұраңыз немесе түзетіңіз. Содан кейін ғана бекітіңіз.
5. Жұмыс біткенде [templates.md](templates.md) ішіндегі «Кезеңнен кейінгі тексеру» промптын беріңіз.
6. Промпт соңындағы «Қабылдағанда өзіңіз тексеретініңіз» бөлімін қолмен тексеріңіз.
7. Бәрі дұрыс болса, PR-ды біріктіріп, келесі кезеңге өтіңіз.

Бір сессияда бір кезеңнен артық бермеңіз: контекст толып, сапа төмендейді.
