# 2-кезең: ядро — редактор, тестілеу, цифрлық із

**Алдын ала шешілетін сұрақтар:** жоқ.
**Қалай беру керек:** жаңа сессия, жоспарлау режимі.

```text
2-кезеңді орында. Алдымен оқы: CLAUDE.md, docs/spec/06-model-components.md
(ядро жолы), 07-functional-requirements.md, 08-assessment-pipeline.md,
12-data-model.md, 13-non-functional.md, 14-security.md (код орындау, академиялық
адалдық), docs/spec/dissertation/task-stages.md.

Осы кезеңнің талаптары: ФТ-24, ФТ-25, ФТ-27, ФТ-29, ФТ-31.

Нәтиже:
1. Студент кабинетіндегі C++ редакторы (Monaco): компиляциялау, өз енгізуімен
   іске қосу, ашық тесттер, тапсыру (ФТ-24).
2. Judge0 арқылы тестілеу: вердиктер OK, WA, TLE, MLE, RE, CE; уақыт пен жад
   (ФТ-31). Тапсыру фондық кезекпен (RQ) өңделеді.
3. Цифрлық із (ФТ-25): код өзгерістері (снапшот немесе diff), компиляция мен
   оның қателері, іске қосу, тест, тапсыру, түсіндірме, уақыт белгісі.
   trace_events тек толығады: UPDATE мен DELETE дерекқор деңгейінде
   бұғатталған. Сервер жауап бермесе, браузер оқиғаларды сақтап, кейін жібереді.
4. Академиялық адалдық белгілері (ФТ-29): кірістіру (paste) оқиғасы мен көлемі,
   терезе ауысуы. Үлкен кірістіру шегі баптауларда; белгі оқытушыға көрінеді,
   студентке айып ретінде көрсетілмейді.
5. Тапсыру кезінде студент шешімін түсіндіреді; жүйе оның өз коды бойынша 2–3
   сұрақ қояды (ФТ-27). Сұрақтарды LLM жасайды: әзірге fake провайдер және
   үлгі сұрақтар.
6. Бақылау жұмысы режимінде бір ғана белсенді сессия.

Қабылдау критерийі:
- Әр seed тапсырманың эталон шешімі OK алады.
- Әр вердикт үшін әдейі дайындалған қате шешім бар (WA, TLE, MLE, RE, CE) және
  күтілген вердиктті алады.
- trace_events-ті өзгерту немесе өшіру әрекеті сәтсіз болатынын тест дәлелдейді.
- Бір бақылау жұмысының ізінен код жазу үдерісін басынан аяғына дейін қалпына
  келтіруге болады (қайта ойнату интерфейсі 6b-кезеңде, бірақ дерек қазір толық).
- Студент коды желіге шыға алмайтыны тестпен тексерілген.

Алдымен жоспар ұсын, бекіткеннен кейін ғана код жаз.
```

**Қабылдағанда өзіңіз тексеретініңіз:** студент ретінде бір тапсырманы шешіп көріңіз; қате шешім жіберіңіз; кірістіру белгісі оқытушыға көріне ме.
