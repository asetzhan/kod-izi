# Қосымша промпттар

## Кезеңнен кейінгі тексеру

Әр кезең біткенде, PR-ды біріктірмес бұрын беріңіз.

```text
N-кезең бітті деп есептейміз. Ештеңе өзгертпей, тек есеп бер:
1. make lint пен make test нәтижесі.
2. Осы кезеңнің әр ID-і бойынша кесте: қай файлда іске асты, қай тест
   тексереді. Жабылмаған ID болса, атап көрсет.
3. Промпттағы қабылдау критерийлерінің әрқайсысы орындалды ма, дәлелі қандай.
4. security-reviewer субагентінің есебі (14-бөлім бойынша).
5. docs/spec/questions.md-ге жаңа сұрақ қосылды ма.
6. CLAUDE.md-ге не қосу керек: жаңа командалар, қайталанған қателер.
7. PR сипаттамасының қазақша жобасы.
```

## Қатені түзету

```text
Қате бар: [не істедім, не күттім, не болды; қай бетте, қай рөлмен].
Алдымен осы қатені қайталайтын тест жаз. Содан кейін түзет. Қатеге
қатысы жоқ файлдарды өзгертпе. Соңында тесттің бұрын құлап, енді өтетінін көрсет.
```

## Талапты өзгерту

```text
Техникалық тапсырмаға өзгеріс: [не өзгереді және неге].
Алдымен docs/spec/ ішіндегі тиісті бөлімді жаңарт және қай ID-лер
өзгеретінін көрсет. Содан кейін кодқа өзгеріс жоспарын ұсын. Мен
бекіткеннен кейін ғана код жаз.
```

## Үзілістен кейін жалғастыру

```text
Жаңа сессия. CLAUDE.md пен docs/spec/questions.md оқы, git log пен ашық
pull request-терді қара. N-кезеңнің қай бөлігі бітпегенін анықта да,
жалғастыру жоспарын ұсын.
```

## Сұраққа жауап бергеннен кейін

```text
docs/spec/questions.md-дегі Q-NN сұрағына шешім жазылды. Оны оқы,
осы шешімге тәуелді жұмысты анықта және жоспар ұсын.
```
