# 3-кезең: талдау, LLM, рубрика, кітаптар

**Алдын ала шешілетін сұрақтар:** Q-08 (қай LLM), Q-09 (шетелдік API), Q-10 (бағалау нұсқаулығы), Q-11 (кітаптарға құқық).
**Қалай беру керек:** жаңа сессия, жоспарлау режимі. Бұл ең үлкен кезең: Claude Code оны бөліктерге бөлуді ұсынса, келісіңіз.

```text
3-кезеңді орында. Алдымен оқы: CLAUDE.md, docs/spec/07-functional-requirements.md,
08-assessment-pipeline.md, 09-teacher-materials.md, 14-security.md (толық),
docs/spec/dissertation/criteria-indicators.md, rubric-descriptors.md,
analysis-methods.md, llm-assessment-instructions.md, seed/rubric_default.json.

Осы кезеңнің талаптары: ФТ-06, ФТ-11, ФТ-13, ФТ-15, ФТ-16, ФТ-32, ФТ-34,
ФТ-35, ФТ-46, ФТ-47, ФТ-48.

Нәтиже:
1. Статикалық талдау (ФТ-32): clang-tidy, cppcheck, күрделілік метрикалары.
2. Рубрика (ФТ-13, ФТ-15): алты критерий, көрсеткіштер, үш деңгейлі
   дескрипторлар seed/rubric_default.json-нан; салмақтар S = 0,3626F +
   0,3641E + 0,2733A; оқытушы өзгерте алады. Оқытушының кітапқа сүйенген
   қосымша талаптары (ФТ-16).
3. Оқу материалдары (ФТ-06, ФТ-11): PDF, DOCX, EPUB, PPTX жүктеу; файл түрі,
   көлемі, MIME тексеру, ClamAV; мәтін бөлек оқшауланған өңдеуіште
   шығарылады; тарау мен бет сақталады; үзінділер pgvector-ға. Тарауды
   тақырыпқа және тапсырмаға «бағалау негізі» ретінде байлау.
4. LLM шлюзі (ФТ-46): провайдер Q-08 бойынша; бір интерфейс; сұрау квотасы.
5. LLM бағасы (ФТ-34, ФТ-35): промпт llm-assessment-instructions.md бойынша,
   дерек блоктарымен; кітап үзінділері мағыналық іздеумен табылады; жауап
   JSON сызбасы бойынша тексеріледі, жарамсыз болса бір рет қайталанады,
   кейін оқытушыға белгіленеді; contradiction_with_tests және
   possible_injection белгілері. Әр бағаға модель мен промпт нұсқасы
   жазылады (ФТ-48).
6. AI-көмекші (ФТ-47): режимдер forbidden, hints_only, open; барлық сұраныс
   журналға жазылады; hints_only режимінде жауап дайын кодқа тексеріледі;
   көмекші промптына жасырын тесттер мен эталон шешім берілмейді.
7. LLM-ге студенттің аты-жөні берілмейді, тек псевдоним.

Қабылдау критерийі:
- LLM жауабының JSON сызбасы тестпен тексерілген; жарамсыз жауап өңделеді.
- Кемінде 20 жұмыстан тұратын prompt injection жиынтығы бар (код
  түсініктемесінде, түсіндірмеде, кітап үзіндісінде). Онда LLM бағасы
  өзгермейді немесе жұмыс оқытушыға белгіленеді. Жиынтық fake провайдермен
  де, нақты провайдермен де (қолмен іске қосылатын тест) тексеріледі.
- Кітап негізіндегі бағалауда әр дәлелде кітап, тарау, бет бар.
- LLM-ге жіберілетін деректе аты-жөн жоқ екенін тест дәлелдейді.
- Жасырын тесттер мен эталон шешім көмекші промптына түспейтінін тест дәлелдейді.
- Тесттерде нақты LLM API шақырылмайды.

Промпт мәтінін мазмұны жағынан өзгертпе: өзгерту керек болса, ұсынысыңды
questions.md-ге жаз. Алдымен жоспар ұсын, бекіткеннен кейін ғана код жаз.
```

**Қабылдағанда өзіңіз тексеретініңіз:** диссертациядағы бірнеше студент жұмысын жүйеден өткізіп, AI бағасын өз бағаңызбен салыстырыңыз; кітап сілтемелері дұрыс бетке апара ма.
