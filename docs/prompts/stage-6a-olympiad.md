# 6a-кезең: олимпиада бөлімі

**Алдын ала шешілетін сұрақтар:** Q-04 (IV деңгей), Q-13 (есептер банкін кім толтырады).
**Қалай беру керек:** пилоттан кейін, жаңа сессия, жоспарлау режимі.

```text
6a-кезеңді орында: олимпиада бөлімі. Алдымен оқы: CLAUDE.md,
docs/spec/04-part2-olympiad.md, 05-task-levels.md, 10-olympiad-functions.md,
seed/stepik_lessons.json, seed/olympiad_resources.json.

Осы кезеңнің талаптары: ОТ-01, ОТ-02, ОТ-03, ОТ-04, ОТ-05, ОТ-06, ОТ-10.

Нәтиже:
1. 2-бөлімнің құрылымы: 4.1 (Stepik 64454), 4.2 (Stepik 1547), 4.3 (жарыс
   практикасы); модульдер мен сабақ сілтемелері seed деректерінен. Бөлім
   1.11 мен 1.12 тақырыптары меңгерілгенде ашылады.
2. Есептер банкі (ОТ-01): тақырып тегтері, деңгей (III немесе IV),
   Codeforces қиындық рейтингі, әр есепке бөлек уақыт пен жад шектеуі
   (16 МБ-тан 1024 МБ-қа дейін).
3. Жарыс режимі (ОТ-02): ICPC (айыппұл уақыты) және IOI (ішкі есептер
   бойынша балл), нәтижелер кестесі, соңғы сағатта кестені тоқтату. Жарыс
   кезінде AI-көмекші өшірулі.
4. Виртуалды контест (ОТ-03): өткен жарысты сол шарттармен қайта жазу.
5. Деңгейге сай ұсыныс (ОТ-04): студент рейтингінен сәл жоғары есептер;
   ауқымы баптауларда (әдепкі +100…+300).
6. «Бір сағат» ережесі (ОТ-05): 60 минутқа дейін талдау жабық; AI кеңестері
   біртіндеп ашылады (бағыт, идея, псевдокод), дайын код берілмейді.
7. Өз тесттерімен тексеру (ОТ-06): тесттерді сақтап, бәрін бір батырмамен
   іске қосу; баяу дұрыс шешіммен салыстыратын стресс-тест.
8. Анықтамалық (ОТ-10): әр модульге Stepik сабақтары мен қосымша материалдар.

Қабылдау критерийі:
- ICPC мен IOI нәтижелер кестесінің есептелуі тестпен тексерілген.
- Жарыс кезінде AI-көмекшіге сұрау жіберу мүмкін емес (тест).
- Бір сағат ережесі уақыт бойынша тексерілген.
- Стресс-тест айырмашылық табылған кірісті көрсетеді.

Алдымен жоспар ұсын, бекіткеннен кейін ғана код жаз.
```

**Қабылдағанда өзіңіз тексеретініңіз:** жаттықтырушымен бірге бір виртуалды контест өткізіп көріңіз.
