# 7-кезең: 3-кезеңнің функциялары

**Алдын ала шешілетін сұрақтар:** Code-DKT үшін GPU немесе бұлттық ресурс бар ма (Q-08).
**Қалай беру керек:** жаңа сессия, жоспарлау режимі.

```text
7-кезеңді орында. Алдымен оқы: CLAUDE.md, docs/spec/07-functional-requirements.md,
10-olympiad-functions.md, 11-architecture.md.

Осы кезеңнің талаптары: ФТ-40, ОТ-07, ОТ-08, ОТ-09.

Нәтиже:
1. Студент моделін кодтың белгілерімен кеңейту, Code-DKT (ФТ-40): PyTorch,
   оқыту мен бағалау скрипттері, BKT-мен салыстыру есебі. Модель болмаса
   немесе нашар болса, жүйе BKT-ға қайтады.
2. Жарыстан кейінгі талдау (ОТ-07): AI шешім талдауын жасайды, қайта шешуге
   тізім құрады; студент шешімін түсіндіреді, алты критерий бойынша қос
   бағалау.
3. Сыртқы платформалар (ОТ-08): Codeforces аккаунтын байланыстыру, Codeforces
   API арқылы шешілген есептер мен рейтингті жинау; Stepik, CSES, AtCoder,
   ACMP есептеріне сілтеме және қолмен белгілеу.
4. Білім картасы (ОТ-09): тақырыптар бойынша меңгеру және рейтинг динамикасы.
5. Авторлық куәлікке өтінімге арналған техникалық сипаттама (docs/ ішінде):
   жүйенің мақсаты, құрамы, архитектурасы, негізгі алгоритмдері.

Қабылдау критерийі: әр ID-ге кемінде бір тест; Codeforces API-ге сұраулар
лимитке сай және қате кезінде жүйе тоқтамайды.

Алдымен жоспар ұсын, бекіткеннен кейін ғана код жаз.
```
