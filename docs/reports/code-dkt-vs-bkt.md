# Code-DKT пен BKT-ны салыстыру (ФТ-40)

Күні: 2026-11-01. Дереккөз: симуляцияланған деректер (`app/ml/dataset.synthetic`): пилоттан бұрын скрипттерді тексеру үшін. Нақты нәтиже пилот деректерімен қайта есептеледі.

Міндет: студенттің келесі әрекетінің дұрыс болатынын болжау. Өлшем: ROC AUC, тест
студенттерінде (оқытуға кірмеген 90 студент). Екі модель де әр студенттің
екінші әрекетінен бастап бағаланады.

| Көрсеткіш | Мәні |
| --- | --- |
| Студенттер (оқыту / тест) | 210 / 90 |
| Әрекеттер | 3600 |
| Білім компоненттері | 5 |
| BKT, AUC | 0.7314 |
| Code-DKT, AUC | 0.7603 |
| Code-DKT дәуірлері (epochs) | 8 |

Қорытынды: Code-DKT BKT-дан жақсы.
Симуляцияланған деректерде оқытылған модель жүйеде ешқашан қолданылмайды.
Жүйе Code-DKT-ны тек нақты деректерде оқытылған және AUC бойынша BKT-дан кемінде
`CODE_DKT_MIN_GAIN` (әдепкі 0,02) жоғары болғанда қолданады. Әйтпесе BKT қолданылады.

Модель: LSTM (жасырын қабат 64), кіріс — білім компоненті мен дұрыстықтың one-hot
векторы және кодтың 44 белгісі (12 метрика мен токендер жұптарының 32 себеттік
хэштелген гистограммасы, `app/ml/features.py`). Оқыту: Adam, келесі әрекеттің
бинарлық кросс-энтропиясы. Есептеу CPU-да (Q-19).
