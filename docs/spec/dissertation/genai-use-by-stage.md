# GenAI құралдарын қолдануды бағалау нәтижелері (3-тарау, 3-кесте)

Дереккөз: Жаксылыков, диссертация «Программалаудан студенттердің білімін бақылаудың интеллектуалдық моделі». Мәтін диссертациядан өзгеріссіз алынды.

Кесте 3 – Программалау әрекетінің кезеңдері бойынша GenAI құралдарын қолдануды бағалау нәтижелері

| Программалау әрекетінің кезеңі | GenAI қолданудың бағаланатын сипаты | Орташа мән |
| --- | --- | --- |
| Есептің мазмұнын түсіну және қойылымын анықтау | Есепті нақтылау, идеяларды қалыптастыру және талаптарды айқындауда GenAI-ді саналы қолдану | 0,64 |
| Шешімді жоспарлау | Талдау, идеяларды қалыптастыру және шешім құрылымын жоспарлауда GenAI-ді қолдану | 0,66 |
| Программалық шешімді іске асыру | GenAI-ді саналы қолдану, ұсынылған шешімді түсіну және бейімдеу | 0,66 |
| Орындалуын бақылау | Тестілеу, қателерді талдау және түзетуде GenAI-ді саналы қолдану | 0,65 |
| Нәтижені қорғау | GenAI-дің қалай және қандай мақсатта қолданылғанын түсіндіру | 0,68 |
