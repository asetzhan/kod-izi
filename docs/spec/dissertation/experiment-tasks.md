# Эксперименттік тексеруде қолданылған программалау тапсырмалары (Қосымша Г)

Дереккөз: диссертацияның Г қосымшасы. Мәтін өзгеріссіз алынды.


I күрделілік деңгейі

1. Берілген n бүтін санының жұп немесе тақ екенін анықтаңыз.

2. Берілген үш санның ең үлкенін анықтаңыз.

3. Берілген n бүтін санының цифрларын кері ретпен шығарыңыз.

II күрделілік деңгейі

1. Берілген массивтегі тақ сандардың қосындысын анықтаңыз.

2. Берілген сөздің палиндром екенін анықтаңыз.

3. Берілген n натурал санының барлық бөлгіштерін анықтаңыз.

III күрделілік деңгейі

1. Берілген санның кез келген екі цифрының орнын ауыстыру арқылы палиндром сан алуға болатынын анықтаңыз.

2. Берілген сандар жиынынан ең жиі кездесетін санды анықтаңыз.

3. Берілген санның цифрларының орнын ауыстыру арқылы бастапқы саннан үлкен ең кіші санды анықтаңыз.
