# Бағалау критерийлері, көрсеткіштер және дерек көздері (1-тарау, 1-кесте)

Дереккөз: Жаксылыков, диссертация «Программалаудан студенттердің білімін бақылаудың интеллектуалдық моделі». Мәтін диссертациядан өзгеріссіз алынды.

Кесте 1 – Программалаудан білімді интеллектуалдық бақылаудың бағалау критерийлері, көрсеткіштері және дереккөздер

| Бағалау критерийі | Блум–Андерсон–Кратвол таксономиясымен сәйкестігі | Негізгі көрсеткіштер | Дерек көздері |
| --- | --- | --- | --- |
| Есептік-мазмұндық түсіну | Түсіну; берілгендер мен талаптар арасындағы байланысты ажыратқанда талдау | Есептің мақсатын, кіріс және шығыс деректерін, шектеулерін дұрыс анықтайды; олардың шешімге әсерін түсіндіреді | Есеп шарты бойынша студенттің жауабы; кіріс–шығыс пен шектеулерге берген түсіндірмесі |
| Алгоритмдік шешім | Белгілі тәсілді қолданғанда қолдану; тәсілдерді салыстырғанда талдау; өзіндік алгоритм құрғанда жасау | Алгоритм қадамдарын қисынды ұйымдастырады; құрылымдарды есепке сай таңдайды; тәсілінің тиімділігін негіздейді | Алгоритм немесе шешу жоспары; код құрылымы; балама тәсілдер туралы студенттің негіздемесі |
| Функционалдық дұрыстық | Шешімді іске асырғанда қолдану; сәтсіз жағдайдың себебін өзі анықтағанда талдау | Программа негізгі және шеттік жағдайларда есеп талабына сай нәтиже береді; студент қате шыққан жағдайды түсіндіреді | Күтілетін нәтижесі белгіленген тестілер; кіріс–шығыс және орындалу нәтижелері; студенттің сәтсіз тестіге түсіндірмесі |
| Код сапасы | Конструкцияларды пайдаланғанда қолдану; код бөліктерінің байланысын ашқанда талдау; өз шешімін сапа талаптарымен салыстырғанда бағалау | Код құрылымы бірізді; атаулар түсінікті; конструкциялар орынды қолданылған; студент құрылымдық таңдауын негіздейді | Программалық код; статикалық талдау нәтижесі; студенттің код құрылымы туралы түсіндірмесі |
| Қатені анықтау және түзету | Себебін анықтағанда талдау; түзету тәсілін таңдағанда бағалау; өзгерісті енгізгенде қолдану | Қатені және оның себебін анықтайды; түзетуді негіздейді; өзгерістен кейін нәтижені қайта тексереді | Қате хабарламасы мен сәтсіз тестілер; код өзгерістерінің тарихы; студент түсіндірмесі; қайта тестілеу нәтижесі |
| Шешімді түсіндіру және негіздеу | Код пен алгоритм қызметін түсіндіргенде түсіну; олардың байланысын ашқанда талдау; тәсілін негіздегенде бағалау | Алгоритм қадамдарын және код бөліктерінің қызметін түсіндіреді; таңдаған шешімінің орындылығын негіздейді | Студенттің ауызша немесе жазбаша түсіндірмесі; алгоритм сипаттамасы; негіздеу сұрақтарына жауаптары |
