## Қорытынды баға

S = 0,3626·F + 0,3641·E + 0,2733·A

F — функционалдық дұрыстық, E — шешімді түсіндіру сапасы, A — GenAI құралдарын пайдалану деңгейі; әрқайсысы 0–100 балл. Салмақтар 31 оқытушының сараптамасы бойынша анықталған (диссертация, 3-тарау). Оқытушы салмақтарды бақылау жұмысына қарай өзгерте алады.

## Диссертацияда жоқ нәрсе

Тәжірибеде LLM-ге берілген бағалау нұсқаулығының толық мәтіні мен E және A компоненттерінің деңгейлік шкалалары диссертация мәтінінде кесте түрінде берілмеген. Бұл — docs/spec/questions.md файлындағы Q-10 сұрағы. Ол шешілгенше llm-assessment-instructions.md файлындағы жоба қолданылады.
