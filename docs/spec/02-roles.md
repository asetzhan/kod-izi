# 2. Пайдаланушылар мен рөлдер

Жүйеде төрт рөл бар. Оқытушы мен жаттықтырушы бір адам болуы мүмкін, рұқсаттары бөлек беріледі.

| Рөл | Негізгі әрекеттері | Модель элементі |
| --- | --- | --- |
| Студент | Тапсырмаларды браузердегі C++ редакторында орындайды, тесттерді іске қосады, рұқсат болса AI-көмекшіден сұрайды, шешімін түсіндіреді, кері байланыс пен ұсынылатын тапсырмаларды көреді, жарыстарға қатысады | Ядро: студенттің программалау әрекеті |
| Оқытушы | Курс, оқу нәтижелері мен бақылау жұмыстарын құрады, модельдің бес компонентін қарап, автоматты толтырылған мазмұнды өзгертеді, кітаптар мен есептер жинақтарын жүктеп, бағалау негізін белгілейді, рубриканы баптайды, GenAI режимін таңдайды, код жазу үдерісін қайта ойнатып көреді, AI бағасын растайды немесе түзетеді, топ аналитикасын қарайды | Оқытушының басқару блогы |
| Жаттықтырушы | Олимпиадалық есептер банкін жүргізеді, жарыстар мен виртуалды контесттер ұйымдастырады, студенттердің сыртқы платформалардағы прогресін бақылайды | Оқытушының басқару блогы (2-бөлім) |
| Әкімші | Пайдаланушылар мен топтарды басқарады, LLM модельдерін қосады және шектейді, жүйе жұмысын бақылайды | GenAI платформасы, инфрақұрылым |
