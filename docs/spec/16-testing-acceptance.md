# 16. Сынау және қабылдау

Жүйе он тексеруден өткенде қабылданады.

- **Тестілеу жүйесі.** Барлық эталон шешімдер OK алады. Дайындалған қате шешімдер күтілген вердиктті (WA, TLE, MLE, RE, CE) алады.
- **Функционалдық талаптар.** Ағымдағы кезеңнің әр ФТ және ОТ талабы жазбаша сценарий бойынша тексеріледі.
- **Автотесттер.** Әр ФТ мен ОТ талабына Claude Code жазған кемінде бір автотест бар, CI барлық тесттен өтеді.
- **Цифрлық іздің толықтығы.** Бақылау жұмысынан кейін әр студенттің код жазу үдерісін басынан аяғына дейін қайта ойнатуға болады.
- **Модель компоненттері.** Бес компонент автоматты толтырылады; оқытушы өзгерткен мән қайта генерациялаудан кейін сақталады; нұсқалар тарихы бойынша кез келген нұсқаға қайтуға болады.
- **AI бағасының сапасы.** Пилотта AI мен оқытушы бағасы арасындағы Pearson, Spearman, MAE және MD есептеледі. Салыстыру базасы — диссертациядағы Claude нәтижесі (MAE = 7,34; r = 0,647). Жүйенің нәтижесі одан төмен болмауы керек.
- **Кітап негізінде бағалау.** Іріктелген жұмыстарда оқытушы AI берген кітап сілтемелерін тексереді: сілтемелердің кемінде 90%-ы тиісті мазмұны бар бетке апаруы керек.
- **Жүктеме.** 100 студент бір уақытта жұмыс істегенде 13-бөлімдегі талаптар орындалады.
- **Қауіпсіздік.** Пилот алдында тәуелсіз ену тесті (pentest) жүргізіліп, сыни және жоғары деңгейдегі осалдықтар жабылады. Студент коды оқшауланған ортадан шыға алмайды, студент басқалардың дерегін көре алмайды. Prompt injection әрекеттері бар жұмыстарда LLM бағасы өзгермейді немесе жұмыс оқытушыға белгіленеді.
- **Пайдаланушылар бағасы.** Оқытушылар мен студенттер сауалнамасы (мысалы, SUS шкаласы) жүргізіледі.
