# 7. Функционалдық талаптар

Талаптар модельдің элементтері бойынша топталған. «Кезең» бағаны талаптың қай кезеңде іске асатынын көрсетеді, оны осы жерден өзгертуге болады.

| № | Модель элементі | Талап | Кезең |
| --- | --- | --- | --- |
| ФТ-01 | Оқытушы блогы | Оқытушы курс құрып, оған топтар мен студенттерді қосады | MVP |
| ФТ-02 | Оқытушы блогы | Оқытушы бақылау жұмысын құрады: тапсырмалар, уақыт, GenAI режимі | MVP |
| ФТ-03 | Оқытушы блогы | Оқытушы AI-дың алдын ала бағасын растайды немесе түзетеді, түзету себебін жазады | MVP |
| ФТ-04 | Оқытушы блогы | Топ бойынша мониторинг тақтасы: критерийлер бойынша деңгейлер мен типтік қиындықтар | 2-кезең |
| ФТ-05 | Оқытушы блогы | Оқытушы студентке жеке тапсырма тағайындайды (жекелендіру және түзету) | 2-кезең |
| ФТ-06 | Оқытушы блогы | Оқытушы курсқа кітаптар, оқу құралдары, дәрістер мен есептер жинақтарын жүктейді (PDF, DOCX, EPUB, PPTX); материалдар тек сол курстың қатысушыларына көрінеді | MVP |
| ФТ-07 | Оқытушы блогы | Модель компоненттерінің панелі: бес компонент модель сызбасы түрінде көрсетіледі; әр жазбада дереккөз белгісі (автоматты, оқытушы, өзгертілген) мен нұсқалар тарихы бар (6-бөлім) | MVP |
| ФТ-08 | 1. Педагогикалық-мақсаттық | Курс тақырыптардан, тақырып оқу нәтижелері мен білім компоненттерінен тұрады | MVP |
| ФТ-09 | 1. Педагогикалық-мақсаттық | Жүйе Stepik сабақтары мен жүктелген кітап бойынша бақылау мақсаттарын, оқу нәтижелерін және білім компоненттерін автоматты ұсынады; оқытушы оларды қолмен толтырып, өзгертеді | MVP |
| ФТ-10 | 1. Педагогикалық-мақсаттық | Әр тапсырма бір немесе бірнеше білім компонентіне байланады | MVP |
| ФТ-11 | 1. Педагогикалық-мақсаттық | Кітап тараулары курс тақырыптарына байланады; әр тапсырма мен бақылау жұмысына «бағалау негізі» болатын тараулар мен беттер белгіленеді | MVP |
| ФТ-12 | 1. Педагогикалық-мақсаттық | Әр тақырып пен тапсырмада Stepik-тегі дереккөз сабағына сілтеме бар (3 және 4-бөлімдер) | MVP |
| ФТ-13 | 2. Критерийлік-бағалау | Рубрика конструкторы: 6 критерий, көрсеткіштер, үш деңгейлі дескрипторлар, салмақтар | MVP |
| ФТ-14 | 2. Критерийлік-бағалау | Әдепкі рубрика диссертацияның 8-кестесінен автоматты толтырылады; LLM дескрипторларды нақты тапсырмаға бейімдеп ұсынады, оқытушы өзгертеді | MVP |
| ФТ-15 | 2. Критерийлік-бағалау | Әдепкі салмақтар: S = 0,3626F + 0,3641E + 0,2733A; оқытушы өзгерте алады | MVP |
| ФТ-16 | 2. Критерийлік-бағалау | Оқытушы кітапқа сүйенген бағалау талаптарын жазады: міндетті әдіс, код жазу стилі, тыйым салынған құралдар (мысалы, STL-сіз шешу) | MVP |
| ФТ-17 | 2. Критерийлік-бағалау | Оқытушы бағалаған жұмыстар әр деңгейдің үлгісі ретінде рубрикаға қосылып, LLM бағасын оқытушы талабына жақындатады | 2-кезең |
| ФТ-18 | 3. Деңгейлік-тапсырма | Тапсырмалар банкі: шарт, деңгей (I–IV), уақыт пен жад шектеуі, ашық және жасырын тесттер, эталон шешім | MVP |
| ФТ-19 | 3. Деңгейлік-тапсырма | Тапсырма деңгейін жүйе төрт белгі бойынша ұсынады (5.2), оқытушы растайды немесе өзгертеді | MVP |
| ФТ-20 | 3. Деңгейлік-тапсырма | Пилоттан кейін әр тапсырманың шешілу үлесі есептеліп, деңгейіне сәйкес келмейтін тапсырмалар оқытушыға белгіленеді | 2-кезең |
| ФТ-21 | 3. Деңгейлік-тапсырма | LLM тапсырма мен тесттердің жобасын жасайды, оның ішінде кітаптың таңдалған тарауы бойынша; оқытушы бекіткеннен кейін ғана жарияланады | 2-кезең |
| ФТ-22 | 3. Деңгейлік-тапсырма | Есептерді импорттау: ZIP мұрағаты (шарт пен тесттер) және Polygon пакеті | MVP |
| ФТ-23 | 3. Деңгейлік-тапсырма | LLM жүктелген есептер жинағынан есептерді бөліп алып, шарт пен мысалдар түрінде жоба жасайды; оқытушы тесттер мен эталон шешімді қосып бекітеді | 2-кезең |
| ФТ-24 | Ядро: программалау әрекеті | Браузердегі C++ редакторы: компиляциялау, іске қосу, өз енгізуімен тексеру, тесттер | MVP |
| ФТ-25 | Ядро: программалау әрекеті | Цифрлық із: код нұсқалары, компиляция нәтижелері мен қателері, тест вердиктері, уақыт белгілері сақталады | MVP |
| ФТ-26 | Ядро: программалау әрекеті | Цифрлық із оқиғалары программалау әрекетінің циклі бойынша белгіленеді: түсіну, жоспарлау, кодтау, тестілеу, түзету, түсіндіру | 2-кезең |
| ФТ-27 | Ядро: программалау әрекеті | Тапсыру кезінде студент шешімін түсіндіреді; жүйе оның өз коды бойынша 2–3 сұрақ қояды | MVP |
| ФТ-28 | Ядро: программалау әрекеті | Оқытушы код жазу үдерісін уақыт шкаласы бойынша қайта ойнатады | 2-кезең |
| ФТ-29 | Ядро: программалау әрекеті | Академиялық адалдық белгілері: кірістіру (paste) оқиғалары мен көлемі, терезе ауысуы цифрлық ізге жазылып, үлкен кірістірулер оқытушыға белгіленеді | MVP |
