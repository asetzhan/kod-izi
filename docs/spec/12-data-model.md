# 12. Деректер моделі

Дерекқор модельдің әр элементін сақтайды. Ең үлкен кесте — цифрлық іздің оқиғалары.

| Нысан | Негізгі өрістері | Модель элементі |
| --- | --- | --- |
| Пайдаланушы, топ | Рөл, аты-жөні, топ, Codeforces аккаунты | Оқытушы блогы |
| Курс, тақырып | Атауы, реті, Stepik сабағына сілтеме, оқу нәтижелері, білім компоненттері | 1 |
| Рубрика | Критерийлер, көрсеткіштер, үш деңгейлі дескрипторлар, салмақтар | 2 |
| Тапсырма | Шарт, деңгей (I–IV), төрт деңгей белгісінің баллдары, тақырып, уақыт пен жад шектеуі, ашық және жасырын тесттер, эталон шешім, білім компоненттері, дереккөз сілтемесі | 3 |
| Бақылау жұмысы, жарыс | Тапсырмалар, уақыт, GenAI режимі, формат (бақылау, ICPC, IOI), рубрика | Оқытушы блогы, 3 |
| Тапсыру | Код, вердикт, тест нәтижелері, уақыт пен жад, статикалық талдау нәтижесі | Ядро, 4 |
| Оқиға (цифрлық із) | Студент, тапсырма, уақыт белгісі, түрі (өзгеріс, компиляция, іске қосу, тест, AI сұрауы), мазмұны | Ядро |
| AI сұхбаты | Сұрау, жауап, режим, модель, соңғы кодпен ұқсастығы | GenAI платформасы |
| Түсіндірме | Студент мәтіні, өз коды бойынша сұрақтар мен жауаптар | Ядро |
| AI бағасы | Критерий, деңгей, дәлел, кітап сілтемелері, сенімділік, модель, промпт нұсқасы | 4 |
| Оқытушы бағасы | Критерий, деңгей, балл, түзету себебі | Оқытушы блогы, 5 |
| Студент моделі | Білім компоненті, меңгеру ықтималдығы, тақырып пен деңгей бойынша K коэффициенті, жаңартылған уақыты | 4, 5 |
| Ұсыным | Келесі тапсырма, себебі (әлсіз критерий немесе тақырып) | 5 |
| Оқу материалы | Атауы, авторы, түрі (кітап, дәріс, есептер жинағы), файл, нұсқасы, курс, құқықты растау белгісі | 1 |
| Үзінді | Материал, нұсқасы, тарау, бет, мәтін, вектор (pgvector) | 4 |
| Материал байланысы | Тақырып немесе тапсырма, тарау, беттер аралығы, «бағалау негізі» белгісі, оқытушының талаптары | 1, 2, 3 |
| Аудит журналы | Пайдаланушы, әрекет, нысан, уақыт, IP мекенжайы | Оқытушы блогы, қауіпсіздік |
| Компонент жазбасы | Компонент (1–5), нысан, мәні, дереккөзі (автоматты, оқытушы, өзгертілген), нұсқа, авторы, уақыты | 1–5, оқытушы блогы |
