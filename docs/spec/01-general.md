# 1. Жалпы мәліметтер

Жүйе диссертацияда ұсынылған интеллектуалдық модельді толық іске асырады. Модель оқытушының басқару блогынан, бес компоненттен, студенттің программалау әрекетінен тұратын ядродан және GenAI платформасынан тұрады.

| Көрсеткіш | Мәні |
| --- | --- |
| Атауы | «Код ізі» (CodeTrace AI), жұмыс атауы |
| Түрі | Веб-жүйе: студент, оқытушы және әкімші кабинеттері |
| Негіздемесі | «Программалаудан студенттердің білімін бақылаудың интеллектуалдық моделі» диссертациясы (6D011100), AP23490592 жобасы |
| Студенттер жазатын тіл | C++ |
| Бөлімдері | 1-бөлім: C++ негіздері бойынша білімді бақылау (Stepik 363). 2-бөлім: олимпиадаға дайындық (Stepik 64454 және 1547, жарыс практикасы) |
| Пайдаланушылары | ЖОО студенттері (6В01507 «Информатика», 6В01509 «Информатика және робототехника» және т.б.), оқытушылар, олимпиада жаттықтырушылары |
| Әзірлеуші | Claude Code: жүйенің бүкіл кодын, тесттерін және құжаттамасын жазады (15-бөлім) |

Жүйенің мақсаты — студенттің білімін соңғы кодпен қатар оны жазу үдерісі бойынша да бағалау. AI алдын ала баға береді, соңғы бағаны оқытушы қояды.
