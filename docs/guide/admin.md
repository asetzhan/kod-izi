# Әкімшіге арналған нұсқаулық

Әкімші бүкіл жүйеге жауап береді:

- пайдаланушыларды, топтарды және рөлдерді басқарады;
- курстарға топтар мен оқытушыларды байлайды;
- аудит журналын қарайды;
- резервтік көшірмені бақылайды.

Жүйеге кіру және телефондағы код (2FA) [ортақ нұсқаулықта](README.md) жазылған. Әкімшіге 2FA міндетті.

## 1. Бірінші әкімшіні жасау

Мұны жүйе орнатылған серверде бір рет жасайды:

```
make create-admin EMAIL=admin@university.kz
```

Команда құпиясөзді сұрайды. Құпиясөз ешбір файлға жазылмайды.

## 2. Әкімші кабинеті

Кіргеннен кейін **«Әкімші кабинеті»** ашылады. Жоғарыда төрт батырма бар:

- **Пайдаланушылар**;
- **Топтар**;
- **Курстар**;
- **Аудит журналы**.

Біреуін бассаңыз, сол бөлім ашылады.

### 2.1. Пайдаланушылар

**Жаңа адам қосу:**

1. **Жаңа пайдаланушы** бөлімінде **Аты-жөні**, **Электрондық пошта** және **Құпиясөз** өрістерін толтырыңыз. Құпиясөз кемінде 12 таңба болады.
2. Адамның рөлін белгілеңіз: **Студент**, **Оқытушы**, **Жаттықтырушы** немесе **Әкімші**. Бір адамға бірнеше рөл беруге болады.
3. **Құру** батырмасын басыңыз. «Пайдаланушы қосылды» деген жазу шығады.
4. Поштасы мен құпиясөзін адамға өзіңіз жеткізіңіз.

**Адамды табу:** **Аты немесе пошта** өрісіне аттың не поштаның бір бөлігін жазыңыз. Керек болса, **Рөлі** тізімінен рөлді таңдаңыз. Содан кейін **Іздеу** батырмасын басыңыз.

**Адаммен жұмыс:** тізімде адамның жанындағы **Басқару** батырмасын басыңыз. Мына батырмалар ашылады:

| Батырма | Не істейді |
| --- | --- |
| **Рөлдерді сақтау** | Белгіленген рөлдерді береді. Өзіңізден әкімші рөлін ала алмайсыз |
| **Құпиясөзді ауыстыру** | Адам құпиясөзін ұмытса, **Жаңа құпиясөз** өрісіне жаңасын жазып, осы батырманы басыңыз. Адам барлық құрылғыда жүйеден шығады. Өз құпиясөзіңізді мұнда ауыстыра алмайсыз: оны басқа әкімші ауыстырады |
| **Бұғаттау** / **Бұғаттан шығару** | Бұғатталған адам жүйеге кіре алмайды, ашық сессиялары бірден жабылады. Өзіңізді бұғаттай алмайсыз |
| **2FA-ны өшіру** | Оқытушы не әкімші телефонын жоғалтса басыңыз. Ол келесі кіргенде 2FA-ны жаңа телефонмен баптайды |
| **Анонимдеу** | Адамның аты мен поштасын біржола өшіреді. Жүйе тағы бір рет сұрайды: **Иә, анонимдеу** батырмасын басқанда ғана орындалады. Мұны қайтару мүмкін емес: анонимделген адамды бұғаттан шығаруға да, оған құпиясөз қоюға да болмайды |

### 2.2. Топтар

1. **Топтың атауы** өрісіне атауын жазыңыз, мысалы «IT-21», және **Құру** батырмасын басыңыз.
2. Әр топтың астында екі тізім бар: **Студенттер** және **Оқытушылар**.
3. Адам қосу үшін тізімнен оны таңдаңыз (**Студентті таңдаңыз** не **Оқытушыны таңдаңыз**) және **Қосу** батырмасын басыңыз. Тізімде сол рөлі бар және бұғатталмаған адамдар ғана көрінеді.
4. Адамды топтан шығару үшін оның атының жанындағы **Өшіру** батырмасын басыңыз. Адамның өзі жүйеден өшпейді, тек топтан шығады.

### 2.3. Курстар

Әр курстың астында екі тізім бар:

- **Байланған топтар.** Курсқа топ байланса, сол топтың студенттері курсты көреді. **Топты таңдаңыз** тізімінен топты таңдап, **Қосу** батырмасын басыңыз.
- **Курс оқытушылары.** Мұнда оқытушы рөлі бар адамды ғана қосуға болады.

**Өшіру** батырмасы топты не оқытушыны курстан ажыратады. Курстың өзі, тапсырмалары мен бағалары өшпейді.

### 2.4. Аудит журналы

Журналда кім, қашан, не істегені жазылады: кірулер (сәтті және сәтсіз), рөл өзгерістері, бұғаттау, құпиясөзді ауыстыру, бағаны растау, баптауларды өзгерту. Журналды ешкім өзгерте де, өшіре де алмайды.

- **Әрекет** өрісіне әрекеттің атауын жазып, сүзуге болады. Мысалы, `login_failed` — сәтсіз кіру, `role_changed` — рөл өзгерді.
- **Кім (ID)** өрісіне адамның нөмірін жазсаңыз, тек оның әрекеттері көрінеді.

## 3. Әзірге тек API арқылы жасалатын нәрселер

Жүйе баптауларын (деңгей ережесі, меңгеру шектері, адалдық белгілері, BKT, шешілу үлесі) әзірге API арқылы өзгертеді: `PUT /api/settings/...`. Олимпиада баптауларын жаттықтырушы өз кабинетінде өзгертеді. API-дің толық сипаттамасы әзірлеу ортасында `http://<мекенжай>/api/docs` бетінде ашылады.

## 4. Күнделікті жұмыс

### 4.1. Жаңа семестр

1. **Пайдаланушылар** бөлімінде студенттер мен оқытушыларды қосыңыз.
2. **Топтар** бөлімінде топтар құрып, оларға студенттер мен оқытушыларды қосыңыз.
3. **Курстар** бөлімінде курсқа топты байлаңыз. Сонда студенттер курсты көреді.
4. Олимпиада курсының жаттықтырушысына **оқытушы** рөлін қосымша беріп, оны сол курстың **Курс оқытушылары** тізіміне қосыңыз.

### 4.2. Деректерді сақтау мерзімі

Белгіленген мерзімі біткен немесе келісімін кері қайтарған студенттердің деректері анонимделеді. Әдепкі мерзім — 365 күн. Мұны мезгіл-мезгіл іске қосыңыз:

```
make retention
```

### 4.3. Резервтік көшірме

- Көшірме күн сайын, шифрланған түрде жасалады:
  ```
  docker compose --profile backup up -d backup
  ```
- Шифрлау кілтін (`BACKUP_PASSPHRASE`) серверден тыс, қауіпсіз жерде сақтаңыз. Кілтсіз көшірмені қалпына келтіру мүмкін емес.
- Қалпына келтіруді тоқсан сайын бөлек дерекқорға сынап көріңіз. Нұсқаулығы `docs/deploy/README.md` файлында.

## 5. Орнату және жаңарту

Жүйені серверге орнату жолы `docs/deploy/README.md` файлында қадамдап жазылған:

- сервер талаптары;
- HTTPS баптау;
- `.env` файлы;
- Judge0 үшін керек cgroup v1.

## 6. Қауіпсіздік ережелері

- `.env` файлын және құпия кілттерді ешкімге жібермеңіз, репозиторийге салмаңыз.
- Әкімші аккаунтын тек әкімші жұмысына қолданыңыз.
- Пилоттан бұрын тәуелсіз ену тестін (pentest) сырттан жүргізіңіз. Бақылау тізімі: `docs/security/pentest-checklist.md`.
- Белгілі тәуекелдер мен оларды жабу жоспары: `docs/security/known-risks.md`.
