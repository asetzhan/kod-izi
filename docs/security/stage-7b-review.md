## Тексерілді, мәселе жоқ

- `torch.load(weights_only=True)`, сондықтан pickle арқылы код орындалмайды. Курс id бүтін сан, жолда traversal жоқ.
- Модельге студенттің шикі коды, аты-жөні кірмейді: тек 12 метрика мен токендер жұптарының хэштелген гистограммасы.
- Симуляцияланған деректерде оқытылған модель жүйеде қолданылмайды.
- Авторлық құжатта құпия, кілт не ішкі мекенжай жоқ.
