Қорытынды: **блоктайтын мәселе жоқ.** 3 medium, 7 low табылды. Төменде әр мәселе және оның күйі.

## Тексерілді, мәселе жоқ

- LLM жазған эталон шешім тек Judge0-де орындалады. JPlag кодты тек талдайды. Shell қолданылмайды. Қалталар `u{user_id}`, файл аты бекітілген, сондықтан path traversal жоқ.
- Кітап пен жинақ мәтіні тек `<data>` блогымен беріледі. Барлық нәтиже «жоба» күйінде.
- Генерация мен бөліп алуда студенттің деректері LLM-ге жіберілмейді.
- Студентке келесі қадамда тапсырма атаулары берілмейді. Оқытушының ұсынысы аяқталмаған бағалаудың тапсырмаларын шығарып тастайды.
- Ұқсастық жұптарын тек екі студентті де оқытатын оқытушы көреді. `similarity_reports` кестесінде RLS бар.
