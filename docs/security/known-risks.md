# Белгілі тәуекелдер

Қауіпсіздік шолуы тапқан, бірақ әзірге толық жабылмаған мәселелер. Әр жолдың «Қашан жабылады» бағаны бар. Жабылған жол осы тізімнен өшіріледі.

Редакторда тек студенттің өз коды тұрады | Monaco жаңарғанда (Dependabot) |

SQL-инъекция `RESET ROLE` арқылы RLS пен `audit_log`/`trace_events` REVOKE-ын айналып өте алады | Бөлек LOGIN рөлі мен миграцияға бөлек URL compose-ты, init-скриптті және деплой тәртібін өзгертеді, сервер әлі белгісіз (Q-02) | SQL тек SQLAlchemy параметрлері арқылы құрылады.
