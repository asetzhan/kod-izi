# 7a-кезеңнің қауіпсіздік шолуы

Күні: 2026-11-01. Тармақ: `stage-7a/olympiad-analysis`. Шолушы: `security-reviewer` субагенті, тек оқу режимінде. Мәселелер PoC арқылы расталды.

Қорытынды: **блоктайтын мәселе жоқ.** 6 medium, 4 low табылды. Төменде әр мәселе және оның күйі.

| # | Мәселе | Күйі |
| --- | --- | --- |
| M1 | Аккаунтты қайта байлау 15 минуттық шектеуді айналып өтіп, Codeforces-қа сұрау кезегін толтыратын | **Түзетілді:** шектеу байлауға да, жаңартуға да қолданылады (Redis, 15 мин) |
| M2 | Бөтен handle-ды байлауға болатын (иесі тексерілмейтін), бір handle-ды екі студент байлай алатын, handle ауысқанда ескі деректер қалатын | **Түзетілді:** студент Codeforces профиліне бір реттік белгі қояды. Ол табылмайынша ештеңе жиналмайды. Бір handle-ды тек бір студент растай алады (бірегей индекс). Handle ауысқанда бұрын жиналған деректер өшіріледі |
| M3 | Кез келген жаттықтырушы барлық студенттің сыртқы деректері мен білім картасын көретін | **Түзетілді:** жаттықтырушы тек өзі жүргізетін курстың студенттерін көреді |
| M4 | `connector` контейнерінде Postgres-тің негізгі логині және Redis паролі бар, интернетке шығуы шектелмеген | **Ішінара:** контейнер `read_only`, `cap_drop: ALL`, `no-new-privileges`. Бөлек DB рөлі мен egress-proxy (тек `codeforces.com:443`) қалды (known-risks) |
| M5 | Веб-бэкенд интернетке шыға алатын (`edge` желісі internal емес еді, бұрыннан бар мәселе) | **Түзетілді:** `edge` енді internal. Порт жариялау үшін тек Nginx бөлек `public` желісінде тұр. Backend пен frontend интернетке шықпайды |
| M6 | Жарысқа қатыспаған студент талдауды оқып алып, содан кейін виртуалды раунд жаза алатын | **Түзетілді:** талдау тек қатысушыларға (ресми немесе виртуалды) көрінеді. Қалғандарына «алдымен виртуалды жазыңыз» деген хабар шығады |
| L1 | Codeforces жауабындағы жарамсыз сандар job-ты құлататын, аккаунт `pending` күйінде қалатын | **Түзетілді:** әр өріс жеке тексеріледі, жарамсыз жазба өткізіледі. Индекс пен сандардың шегі тексеріледі |
| L2 | Жауап көлемі және URL-дағы индекс | **Түзетілді:** индекс `^[A-Z][0-9]?$` тексеріледі, сілтеме API деректерінен құрастырылады. Жауапты ағынмен шектеп оқу қалды (жауап ең көбі 2000 жазба) |
| L3 | Ажырату мен синхрондау бір уақытта жүргенде жиналған деректер қалуы мүмкін | Қалды: терезесі тар, known-risks тізімінде |
| L4 | Талдауды жариялау мен шешімді растау аудитке жазылмайтын | **Түзетілді:** `contest_analysis_edited`, `external_solve_verified` |

Тесттер: `test_ot08_a_handle_is_verified_for_one_student_only`, `test_ot08_codeforces_sync_gathers_solves_and_rating` (расталмаған аккаунт пен жарамсыз жазба), `test_ot08_linking_needs_consent_and_unlinking_removes_the_data` (қайта байлау шектеуі, жаттықтырушының шекарасы), `test_ot09_knowledge_map_by_topic_and_rating_over_time` (жаттықтырушының шекарасы), `test_ot07_ai_analysis_is_published_by_the_coach` (қатыспаған студент).

## Тексерілді, мәселе жоқ

- codeforces.com-ға тек handle жіберіледі. Келісім міндетті. Ажыратқанда жиналған деректер өшеді. Redirect-ке ерілмейді.
- Қолмен белгіленетін сілтемелер нақты хост бойынша тексеріледі, `javascript:` сілтемесі мүмкін емес.
- Талдау мен түсіндірме бойынша шектеулер сақталған. AI бағасы мұғалім растағанша жасырын.
- Үш жаңа кестеде RLS бар.
