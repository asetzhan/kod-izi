# Тапсырма пакетінің форматы (ZIP)

Оқытушы тапсырманы ZIP мұрағаты түрінде импорттай алады (ФТ-22). Курс бетінде «Тапсырманы импорттау» батырмасын басыңыз немесе API-ді пайдаланыңыз: `POST /api/courses/{id}/tasks/import`. Импортталған тапсырма әрқашан «жоба» мәртебесінде түседі. Оқытушы деңгейді растап, тапсырманы бекіткенге дейін студент оны көрмейді.

## Құрылымы

```text
statement.md      міндетті: шарт (Markdown); бірінші «# » жолы атау болады
input.md          қалауыңызша: кіріс форматы
output.md         қалауыңызша: шығыс форматы
solution.cpp      қалауыңызша: эталон шешім
config.json       қалауыңызша: баптаулар (төменде)
tests/01.in       тесттің кірісі
tests/01.out      тесттің күтілетін шығысы
tests/02.in ...
```

Барлық файл бір папкаға салынып, сол папка мұрағатталса да болады.

## config.json

| Өріс | Мағынасы | Әдепкі мәні |
| --- | --- | --- |
| `title` | Атауы, `statement.md`-дегі тақырыптың орнына қолданылады | `# ` жолы |
| `key` | Тапсырманың тұрақты кілті, мысалы `EXP-I-1` (қайталанбауы керек) | жоқ |
| `topic` | Курс тақырыбының коды, мысалы `1.4` | жоқ |
| `knowledge_components` | Білім компоненттерінің кодтары, мысалы `["cond.if_else"]` | `[]` |
| `features` | Деңгейдің төрт белгісі, әрқайсысы 0–2: `knowledge_actions`, `algorithm_freedom`, `edge_cases`, `justification` | жоқ |
| `level` | `I`, `II`, `III` немесе `IV`. `features` берілсе, ереже бойынша шыққан деңгеймен сәйкес келуі керек | ережеден |
| `level_rationale` | Деңгейдің негіздемесі | бос |
| `time_limit_ms` | Уақыт шектеуі (100–20000) | 1000 |
| `memory_limit_kb` | Жад шектеуі (16384–1048576) | 262144 |
| `reference_language` | `cpp17` немесе `cpp20` | `cpp17` |
| `public_tests` | Студентке мысал ретінде көрінетін тесттердің нөмірлері, мысалы `["01", "02"]` | `["01"]` |
| `source_url` | Дереккөзге сілтеме (мысалы, Stepik сабағы) | жоқ |
| `source_note` | Дереккөз туралы ескерту | бос |

`public_tests` тізімінде жоқ тесттердің бәрі жасырын болады. Жасырын тесттер студентке ешбір API арқылы берілмейді.

## Polygon пакеті

Мұрағаттың түбірінде `problem.xml` болса, ол Polygon пакеті ретінде оқылады:

- атауы `names/name` элементінен алынады (орысша, ағылшынша немесе қазақша);
- шарты `statement-sections/<тіл>/legend.tex`, `input.tex`, `output.tex` файлдарынан алынады;
- уақыт пен жад шектеуі `judging/testset` бөлімінен алынады;
- тесттер `tests/01`, `tests/01.a` файлдарынан алынады; `sample="true"` белгісі бар тесттер ашық болады;
- эталон шешім `tag="main"` белгісі бар шешімнен алынады.

Polygon-да **толық пакет** (full package) жинау керек. Linux пакетінде тесттер жоқ, ол «тесттер жоқ» қатесін береді.

## Қателер

Импорт сәтсіз болса, жүйе қатенің кодын және түсіндірмесін қайтарады. Мысалы:

| Код | Себебі |
| --- | --- |
| `not_zip` | Файл ZIP мұрағаты емес |
| `missing_statement` | `statement.md` файлы жоқ |
| `unpaired_test` | Бір тесттің `.in` немесе `.out` файлы жетіспейді |
| `no_tests` | Тест жоқ |
| `bad_config` | `config.json` қате немесе мәні рұқсат етілген аралықтан тыс |
| `unsafe_path` | Мұрағатта `..` немесе абсолютті жол бар |
| `unknown_topic`, `unknown_kc` | Курста мұндай тақырып немесе білім компоненті жоқ |
| `level_mismatch` | `level` мен `features` бір-біріне сәйкес келмейді |
| `polygon_tests_missing` | Polygon пакетінде тесттер жиналмаған |

Шектеулер: мұрағат 10 МБ-тан аспауы керек, ашылған күйінде 64 МБ-тан аспауы керек, 1000-нан көп файл болмауы керек, бір тест 8 МБ-тан аспауы керек.

Үлгі ретінде `seed/tasks/experiment/` ішіндегі тоғыз эксперимент тапсырмасын қараңыз.
